Y# Files
- script.js is the file containing vanilla js. This is the only js being used
- styles.css contains custom css
- index.html contains all the html

# Code style
- Use tailwind classes wherever possible. Use inline style tag for styles that cannot be applied with tailwind css
- Use vanilla js
- Use GSAP for animation and lenis for smooth scroll
- HTML should be responsive for all devices i.e mobile/tabs/desktop/UHDs etc
- Images and assets would go inside assets folder


# Workflow
- Be sure to typecheck when you’re done making a series of code changes
- Prefer running single tests, and not the whole test suite, for performance
